## 修改样式配置

### 位置

在 `compare_methods.py` 文件的第35-66行，找到 `METHOD_CONFIGS` 字典：

```python
METHOD_CONFIGS = {
    'Ours': {
        'color': '#E91E63',      # 修改颜色
        'linestyle': '-',        # 修改线型
        'linewidth': 3.5,        # 修改线宽
        'marker': 'o',           # 修改标记
        'markersize': 8,         # 修改标记大小
        'markevery': 30,         # 修改标记间隔
        'alpha': 1.0,            # 修改透明度
        'zorder': 10,            # 修改图层顺序（越大越在上层）
        'label': 'Ours',         # 修改图例标签
    },
    # ... 其他方法
}
```

### 颜色代码

可以使用以下方式指定颜色：

1. **十六进制代码**: `#E91E63`
2. **颜色名称**: `'red'`, `'blue'`, `'green'` 等
3. **RGB元组**: `(0.91, 0.12, 0.39)` (0-1范围)

### 线型选项

- `'-'` 或 `'solid'`: 实线
- `'--'` 或 `'dashed'`: 虚线
- `'-.'` 或 `'dashdot'`: 点划线
- `':'` 或 `'dotted'`: 点线

### 标记选项

- `'o'`: 圆形
- `'s'`: 方形
- `'^'`: 三角形（向上）
- `'v'`: 三角形（向下）
- `'d'`: 菱形
- `'p'`: 五边形
- `'x'`: 叉号
- `'+'`: 加号
- `'*'`: 星号
- `None`: 无标记

### 图层顺序（zorder）

- 数值越大，图层越靠上
- Ours: 10（最上层）
- Platform: 9
- Oracle-PPO: 8
- 其他方法: 3-5

## 确保线条清晰可见的技巧

### 1. 调整线宽

如果线条重叠看不清，可以：
- 增加重要方法的线宽（如Ours）
- 减少不重要方法的线宽

### 2. 调整透明度

- 重要方法使用高透明度（alpha=1.0）
- 次要方法使用较低透明度（alpha=0.7-0.8）

### 3. 使用不同的线型

- 重要方法使用实线
- 次要方法使用虚线或点线

### 4. 调整标记

- 重要方法使用较大的标记
- 减少标记密度（增加markevery值）

### 5. 图层顺序

- 确保重要方法在最后绘制（zorder最大）
- 代码已按zorder排序绘制

## 注意事项

1. **颜色对比度**: 确保所有颜色在白色背景上清晰可见
2. **重叠处理**: 使用不同的线型和标记避免重叠混淆
3. **打印友好**: 所有颜色在黑白打印时也能区分（通过线型）
4. **色盲友好**: 避免只依赖颜色区分，同时使用线型和标记
